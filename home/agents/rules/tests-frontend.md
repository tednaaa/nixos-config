- NEVER test visual details: colors, classes, spacing, icons, static copy.
- NEVER test the framework doing its job: `v-model` writing state, a prop reaching the template, a static list rendering.
- Assert a visual state through what assistive tech sees, never classes; add the missing semantic attribute when needed:
  - invalid input — `aria-invalid="true"`, not `bg-destructive`
  - current item — `aria-current`, not a highlight class
  - toggled button — `aria-pressed`, not an active class
  - anything else — role and accessible name
