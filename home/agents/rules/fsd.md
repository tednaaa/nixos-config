- Cross-slice imports go through the slice's public `index.ts`: `@/entities/indicator`, never `@/entities/indicator/indicators`. Relative imports inside a slice and page-local imports are fine.
- `index.ts` is the only re-export point. Implementation files (`variants.ts`, SFCs, `types.ts`) export their own declarations, never a sibling's.
- FSD is followed loosely: don't refactor working code only for layer direction, even when a plan lists it.
